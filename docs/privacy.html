Privacy Policy: Future Pulse Uploader

Last updated: 19 October 2026

The Future Pulse Uploader is a private tool used only by its owner to publish the owner's own videos.

What data it uses

  • It uses access to the owner's own YouTube, Instagram and TikTok accounts only to upload videos, set thumbnails and post a comment on those videos.
  • It does not access, collect, store, sell or share data about any other person.
  • Login tokens are stored encrypted in GitHub Secrets and are used only by the owner's automation.

Google user data

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
